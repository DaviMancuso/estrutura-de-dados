# Lista Duplamente Ligada

Atividade desenvolvida em Python para a disciplina de Estrutura de Dados.

O objetivo é implementar uma lista duplamente ligada, onde cada nó possui uma referência para o elemento anterior e para o próximo elemento da lista.

## Funcionalidades

- Inserir elemento no início;
- Inserir elemento no final;
- Inserir elemento em uma posição;
- Remover o primeiro elemento;
- Remover o último elemento;
- Mostrar os elementos da lista.

## Estrutura do Nó

Cada nó possui:

- `valor`: valor armazenado;
- `ant`: referência para o nó anterior;
- `prox`: referência para o próximo nó.

## Exemplo

Uma lista com os valores 10, 20 e 30 possui a seguinte estrutura:

10 <-> 20 <-> 30
